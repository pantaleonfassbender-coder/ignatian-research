Rights. The writings of Ignatius of Loyola (1491–1556) are long out of copyright; the modern translations are not. This site therefore ships the full text of one work only — Letters and Instructions, vol. I, translated by D. F. O'Leary (1914), which is in the public domain. For the five in-copyright translations it ships no running text at all, but only derived data: canonical citation anchors, counts, registers and networks, together with editorial matter written for this site. Their full-text functions operate solely on a copy you load into your own browser, which is never uploaded.

Open the in-copyright works

Full-text functions for the five modern translations run entirely in your browser. Drop in a PDF and this page will identify which work it is, read its text layer, and store it in your own device storage. Nothing is uploaded; only the passages you actively query in the dialogue leave your machine.

Status

Each work can also be opened from a named file directly, which overrides the recognition, and removed again if the wrong volume was filed under it.

Opening a work enables concordance, canonical citation of hits, and the evidence mode of the dialogue.
